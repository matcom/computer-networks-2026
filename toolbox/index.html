Network Toolbox

The toolbox is not a command catalogue. Start from a concrete question, choose the narrowest useful evidence source, record the observation, and keep observation separate from interpretation.

Choose the question first

Section titled “Choose the question first”
Question Start here Field guide
What physical/link properties can this host observe? ip link, ethtool, iw Physical and link evidence
Which interfaces, addresses, routes, neighbors, and sockets does the kernel know? ip, ss Host network state
What packets are visible at this observation point? tcpdump, TShark, Wireshark Packet capture
Where does reachability or latency change along a path? ping, traceroute, mtr Path diagnostics
Is capacity, queueing, or loss limiting performance? iperf3, ping, tc Performance experiments

Evidence has boundaries

Section titled “Evidence has boundaries”

A successful command proves only what that observation point and protocol can establish. Combine host state, path probes, packet capture, and controlled performance measurements when one witness is not enough.
