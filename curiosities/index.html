Workbench · Laboratory BootcampYour computer can network with itself

The loopback interface lets the full IP and transport stack operate without a packet leaving the machine. It is one reason localhost experiments are so useful: they exercise real socket and protocol machinery while removing the physical network from the experiment.

Workbench · Laboratory Bootcamplocalhost can succeed while the real network is completely broken

A service bound to loopback can exercise sockets, TCP, and application framing even when the machine has no usable external route, Wi-Fi association, or Ethernet carrier. That makes localhost unusually valuable for isolating application/transport bugs from link and routing problems.

Chapter 1 · Internet ArchitectureThe Internet is not one network

A browser request can cross a home or campus LAN, an access provider, transit networks, Internet exchange points, and a content provider before reaching a service. What makes this look like one Internet is agreement on a small set of interoperable protocols, not ownership by one organization.

Chapter 1 · Internet Architectureone Web request can cross networks owned by organizations that never coordinate per request

A browser transaction can traverse campus access, an ISP, an exchange point, transit networks, and a content provider. None of those organizations needs to ask the others for permission for each packet; interoperability comes from shared protocol contracts and independently maintained routing policy.

Chapter 2 · Physical Layer: Signals and MediaA faster link does not make a bit outrun physics

Upgrading from 1 Gb/s to 100 Gb/s can reduce serialization by two orders of magnitude, yet the propagation time across the same fiber route changes almost not at all. Capacity and propagation speed are different physical properties.

Chapter 2 · Physical Layer: Signals and Mediafour symbol states can carry two bits—but only if the receiver can still tell them apart

Increasing bits per symbol sounds like free capacity until noise enters the picture. More symbol states usually place decision regions closer together, so the receiver needs enough SNR, better coding, or lower error targets to distinguish them reliably.

Chapter 3 · Network PerformanceBandwidth cannot beat the speed of light

A very high-capacity link can serialize data quickly, but it cannot remove propagation delay. Long-distance applications therefore care about both bandwidth and RTT; increasing one does not automatically fix the other.

Chapter 3 · Network Performancea tiny packet can spend more time traveling than being transmitted

On a very fast long-distance link, serialization for a small packet can be microseconds while propagation is milliseconds. For interactive protocols, shaving bytes may barely matter compared with removing an RTT dependency.

Chapter 4 · Ethernet and Local NetworksClassic Ethernet collisions are mostly history

CSMA/CD is famous because early Ethernet nodes shared one collision domain. Modern switched full-duplex Ethernet normally gives each endpoint its own link, so collision detection is no longer part of ordinary operation even though the historical mechanism remains important for understanding Ethernet’s evolution.

Chapter 4 · Ethernet and Local Networksa switch learns from the source, not from the destination

Learning Ethernet switches update their forwarding knowledge from the source MAC address of frames they receive. The destination tells the switch where the sender wants the frame to go; it does not prove where that destination currently lives.
